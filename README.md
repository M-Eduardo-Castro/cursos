## Curso Básico de HTML, CSS e JavaScript

Este é um curso **gratuito e introdutório** para quem quer aprender desenvolvimento web do zero, com foco em **HTML5**, **CSS3** e **JavaScript** moderno.


🚀 Conteúdo do Curso

✅ **HTML5**: estrutura, semântica, listas, imagens, links, formulários
✅ **CSS3**: estilos, cores, fontes, layout com Flexbox e Grid
✅ **JavaScript**: lógica de programação, DOM, eventos, interatividade básica
✅ Publicação do site com GitHub Pages, Vercel e HostGator

🎓 Objetivo

Capacitar iniciantes a criarem seus próprios sites do zero com tecnologia web, e prepará-los para avançar para o mercado com boas práticas e organização.
